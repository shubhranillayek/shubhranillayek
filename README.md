### What is AgentForge?

[AgentForge](https://github.com/shubhranillayek/agentforge) is my lightweight, MIT-licensed Python agent toolkit. It provides a tool-using agent loop and bounded in-memory conversation history; you supply the LLM adapter. It is an alpha project, not a hosted AI service.
